# Awesome (njg4ne)

[![License: CC BY-SA 4.0](https://img.shields.io/badge/License-CC%20BY--SA%204.0-lightgrey.svg)](LICENSE)

A personal take on the [awesome list](https://github.com/sindresorhus/awesome) tradition. Instead of one topic per list, this repo collects many awesomes in one place: favorite tools and resources, often preferred over their competitors.

Entries are short on purpose. Each one links out so you can explore further.

## Contents

1. [Development](development/README.md): containers, package managers, operating systems, shells, terminals, editors, and version control
2. [AI-Assisted Programming](ai/README.md): coding assistants, agent context standards, and principles
3. [Data and Statistics](data/README.md): languages for analysis and graphics output
4. [Documents and PDFs](documents/README.md): accessible PDFs, viewing and programming PDFs, typesetting, and presentations
5. [Design](design/README.md): graphic design and vector image conversion
6. [Research](research/README.md): reference management and writing
7. [Teaching](teaching/README.md): tools for educators
8. [Hosting and Domains](hosting/README.md): DNS, domains, and static sites

## Highlights

- [Podman](https://podman.io) over Docker for OCI containers
- [pnpm](https://pnpm.io) for Node.js packages
- [veraPDF](https://verapdf.org) and the [texlive.net tag viewer](https://texlive.net/showtags) for checking accessible PDFs
- [Typst](https://typst.app) for quick documents and SVGs of code
- [Cloudflare](https://www.cloudflare.com) for domains and edge hosting
