## Graphic Design

- [Figma](https://www.figma.com) is excellent for graphic design and for making SVGs, PDF images, and raster images.

## Vector Conversion (CLI)

These are essential for converting between kinds of vector images (SVG, PDF, EPS, and so on) from the command line.

- [Inkscape](https://inkscape.org) is a full vector editor with a [command-line interface](https://inkscape.org/doc/inkscape-man.html) for exporting and converting files.
- [MuPDF](https://mupdf.com) includes [`mutool`](https://mupdf.readthedocs.io/en/latest/tools/mutool.html), a set of command-line tools for converting, extracting from, and processing PDFs and other documents.
