## Reference Management

- [Zotero](https://www.zotero.org) is a free, open-source reference manager and an essential research tool.
  - [ZotMoov](https://github.com/wileyyugioh/zotmoov) moves and renames attachments into a folder you choose and links them back to Zotero. It's a useful replacement now that [ZotFile](https://github.com/jlegewie/zotfile) has been deprecated.

## Writing

- [Microsoft Word](https://www.microsoft.com/microsoft-365/word) works with the [Zotero Word plugin](https://www.zotero.org/support/word_processor_integration) for citations.
- For LaTeX, Typst, and accessible PDF output, see [Documents and PDFs](../documents/README.md).
