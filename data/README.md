## Languages

- [R](https://www.r-project.org) is the preferred language for serious statistics.
- [Python](https://www.python.org) is the choice for smaller data cleaning tasks and similar work, maybe even over R.

## Graphics Output

- [Cairo](https://www.cairographics.org) is a graphics library that R can use to write SVGs, through the built-in [cairo devices](https://stat.ethz.ch/R-manual/R-devel/library/grDevices/html/cairo.html) or the [Cairo](https://cran.r-project.org/package=Cairo) package.
  - It's worth finding early. It organizes layers more sanely, which would have made code-generated SVGs much easier to edit afterward (for example in [Inkscape or Figma](../design/README.md)).
